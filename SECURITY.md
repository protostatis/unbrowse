# Security policy

## Supported versions

Security fixes are applied to the latest published Unbrowser release. Older
releases are not maintained after a newer release is available.

| Version | Supported |
|---|---|
| Latest published release | Yes |
| Older releases | No |

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/protostatis/unbrowser/security/advisories/new)
so the report and any reproduction details remain private while they are
investigated.

Include, when available:

- the affected Unbrowser version and install path;
- operating system and architecture;
- a minimal reproduction;
- the expected and observed behavior;
- the security impact; and
- relevant logs with credentials, cookies, tokens, and private data removed.

Reports about the local binary, Python package, container image, release
artifacts, or repository workflows are in scope. General support requests and
feature ideas belong in the public issue tracker.

Please allow time to reproduce and assess the report before public disclosure.
The project does not currently operate a paid bug-bounty program.
